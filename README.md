# Aptick

Aptick is an Android habit-tracking application that helps users monitor daily consistency through a simple calendar interface. Users can mark completed days, review monthly progress, and maintain their tracking history.

## Features

- **Monthly Calendar:** Navigate between months and view tracked dates.
- **Daily Tracking:** Mark dates with green check marks to record completion.
- **Progress Overview:** View monthly tracking progress.
- **Local Data Persistence:** Retain tracked dates between app sessions.
- **Theme Support:** Switch between light and dark modes.

## Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Local Storage:** SharedPreferences
- **Build System:** Gradle
- **Development Environment:** Android Studio

## Run Locally

### Prerequisites

- Android Studio
- Android SDK
- A JDK compatible with the project's Gradle configuration

### Setup

Clone the repository:

```bash
git clone https://github.com/vijayasai220/Aptick.git
```

Open the project in Android Studio, allow Gradle synchronization to complete, and run the application on an emulator or connected Android device.
